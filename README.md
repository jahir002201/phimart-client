# 🛒 PhiMart — E-commerce Platform

**PhiMart** is a modern full-stack e-commerce platform built with **React**, **Django REST Framework**, and **PostgreSQL**. It provides a complete shopping experience with authentication, product management, cart and order processing, reviews, image uploads, and an administrative dashboard.

## 🚀 Features

* 🔐 JWT-based authentication
* 👤 User registration and login
* 🛍️ Product browsing and management
* 🔎 Product search and filtering
* 🛒 Shopping cart management
* 📦 Order placement and management
* ⭐ Product reviews
* 🖼️ Product image uploads
* 👨‍💼 Admin dashboard
* 📱 Responsive user interface
* 🔗 RESTful API architecture

## 🛠️ Tech Stack

### Frontend

* React
* Vite
* Tailwind CSS
* DaisyUI

### Backend

* Django
* Django REST Framework
* JWT Authentication

### Database

* PostgreSQL

## 🏗️ Architecture

```text
React + Vite Frontend
        │
        │ REST API
        ▼
Django REST Framework
        │
        ├── Authentication
        ├── Products
        ├── Cart
        ├── Orders
        └── Reviews
        │
        ▼
PostgreSQL
```
